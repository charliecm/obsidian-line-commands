# Changelog

## 1.4.0 (2026-10-02)

- Added "Copy selection or line" and "Cut selection or line" commands, which act on the selected text or on the cursor line when nothing is selected

## 1.3.0 (2026-08-07)

- Added "Insert line above" and "Insert line below" commands, continuing list/task/indent markers
- Fixed "Paste before line" and "Paste after line" not reliably placing the cursor at the end of the pasted text

## 1.2.0 (2026-08-06)

- Extended "Select lines" command to select downward in subsequent runs (thanks @nheath)
- Updated dependencies, added tests, and addressed warnings from plugin review

## 1.1.0 (2025-02-25)

- Added “Duplicate lines” command (thanks @adventkranz)

## 0.1.0 (2024-02-28)

- Initial release
